Mushroom alarm

Flagged means the model raises an alarm for a potentially poisonous mushroom. It is a prediction, not proof that the mushroom is inedible. Not flagged does not mean safe to eat.

Both options use the same Extra Trees model. A lower cutoff raises more alarms: it catches more poisonous labels, but also flags more edible labels by mistake. The default cutoff raises fewer false alarms, but misses more poisonous labels.

Examples are real training rows. Blank means missing. Category inputs use the dataset's letter codes.

Load an example, then check the rule.

An unflagged mushroom is not proven edible. This coursework model cannot establish safety.

Next-day Citi Bike rides

The model needs 28 completed daily totals, in order. Weather models need forecast inputs too. If the GRU option has no forecasts (an empty list), it uses counts-only XGBoost. Invalid partial forecasts are rejected.

A historical input example is provided. No live data feed is connected.

Frozen release: final test

Extra Trees uses the lower alarm cutoff. The bike release uses 75% GRU / 25% CatBoost, with counts-only XGBoost when forecasts are missing. We chose both from development results, then locked the files before testing.
